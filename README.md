# NexOS

### Fast. Modern. Open.

NexOS is an operating system project inspired by ChromiumOS, with a vision of bringing modern computing, security, and broad application compatibility to a wide range of hardware.

**NexOS is currently under development.** No public bootable installation images are available yet.

---

## Project Vision

Our goal is to develop a modern operating system platform designed for:

- Web applications and modern browsing
- Linux application support
- Android application compatibility
- Windows application compatibility through technologies such as Wine and Proton
- Multiple hardware platforms and processor architectures
- A clean, modern desktop experience

These are development goals, not currently available features.

## Planned Editions

| Edition | Target Hardware |
|---|---|
| NexOS Intel Lite | Selected Intel Celeron, Atom, and Pentium systems |
| NexOS Intel | Selected 3rd–6th generation Intel Core systems |
| NexOS Intel Pro | Selected 7th–14th generation Intel Core systems |
| NexOS Intel Ultra | Supported Intel Core Ultra systems |
| NexOS AMD | Selected AMD processors and Radeon graphics |
| NexOS NVIDIA | Selected NVIDIA platforms |
| NexOS For You | Chromebooks, ARM computers, and selected Surface devices |
| NexOS VM | Virtual machines on x86_64 and ARM |
| NexOS SBC | Raspberry Pi and Orange Pi boards |

Hardware support is planned and has not yet been fully tested or verified.

## Planned Features

- ChromiumOS-based foundation
- Security-focused system architecture
- Modern NexOS desktop interface
- Linux application compatibility
- Android application compatibility
- Windows application compatibility
- Hardware-specific editions
- System and security updates
