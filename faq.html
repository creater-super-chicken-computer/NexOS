Frequently Asked Questions

Find answers about NexOS, planned hardware support, application compatibility, development, and future releases.

01. What is NexOS?

NexOS is an operating system project planned around the ChromiumOS foundation. Its goal is to provide a modern desktop experience with web applications, Linux tools, and additional application compatibility.

PROJECT IN DEVELOPMENT

02. Which devices will NexOS support?

Planned hardware targets include selected Intel, AMD, NVIDIA-based, and ARM systems, as well as virtual machines and single-board computers such as Raspberry Pi and Orange Pi. Compatibility will depend on testing and available drivers.

HARDWARE SUPPORT PLANNED

03. Will NexOS support Linux applications?

Linux application support is planned. The project aims to provide compatibility with selected Linux tools and development applications. This feature is not available yet.

PLANNED FEATURE

04. Will NexOS support Android applications?

Android application compatibility is a development goal. Availability will depend on the chosen implementation, hardware, and testing.

PLANNED FEATURE

05. Will NexOS support Windows applications?

The project plans to investigate compatibility technologies such as Wine and Proton for selected Windows applications and games. This does not mean native Windows application support, and compatibility is not currently available.

PLANNED FEATURE

06. When will NexOS be available to download?

NexOS does not have a public installation release yet. Installation images will be published after development, hardware testing, and release preparation are complete.

NO PUBLIC DOWNLOADS YET

07. Will NexOS be free?

The project is exploring different editions and distribution options. Some editions may be free, while a planned NexOS For You subscription may offer additional services. Final pricing and licensing details have not been announced.

DETAILS NOT FINALIZED

08. Can I install NexOS on my computer today?

Not yet. NexOS is under development and no public, bootable installation image is currently available. Please do not erase or modify your computer's existing operating system expecting to install NexOS.

INSTALLATION NOT AVAILABLE

09. How can I follow NexOS development?

Visit the NexOS website and its Release Notes and Developer Center pages for project information and future development updates.

FOLLOW PROJECT UPDATES
Important: NexOS is under development.

All hardware compatibility, application support, and installation features described on this page are planned goals unless explicitly stated otherwise. No public installation downloads are currently available.
