Development Roadmap

Explore the development goals and planned milestones for NexOS, from the website foundation to future operating system releases.

PHASE 01

Website & Project Foundation

Establish the NexOS identity, project website, support resources, and initial development plans.

  • NexOS branding and homepage
  • Edition information pages
  • Support Center and documentation pages
  • FAQ and project information
WEBSITE FOUNDATION COMPLETED
PHASE 02

Desktop Interface Prototype

Develop and refine the visual desktop experience and explore the core interface design.

  • Desktop interface concept
  • Window and application layout exploration
  • Taskbar and launcher design
  • Interface improvements and testing
PROTOTYPE BUILT — FURTHER WORK PLANNED
PHASE 03

ChromiumOS Foundation

Investigate and establish the technical foundation for a NexOS operating system based on ChromiumOS.

  • Review ChromiumOS source and build requirements
  • Establish a reproducible build environment
  • Explore NexOS system customization
  • Plan system security and update architecture
PLANNED
PHASE 04

Hardware & Driver Compatibility

Investigate hardware support and validate devices through development builds and testing.

  • Selected Intel and AMD platforms
  • Selected NVIDIA and ARM platforms
  • Graphics, networking, audio, and storage drivers
  • Virtual machine and single-board computer testing
PLANNED
PHASE 05

Application Compatibility

Research additional application environments and compatibility technologies.

  • Linux application support
  • Android application compatibility research
  • Windows application compatibility through Wine or Proton
  • Web applications and app distribution
PLANNED
PHASE 06

Testing & First Public Release

Prepare NexOS for public testing after the technical foundation and hardware validation have progressed sufficiently.

  • Internal development builds
  • Installation and recovery testing
  • Security and stability testing
  • Release documentation and verified downloads
PLANNED
Important: Roadmap information

This roadmap describes development goals, not guaranteed release dates. Features, hardware targets, and project priorities may change as development progresses. NexOS is under development and no public bootable installation image is currently available.
